# Additive-Manufacturing-Error-Correction
New changes to the project. With a better understanding of machine learning, we can better test certain parameters for correlation.
Originally we were recording many different changes in printing parameters without having a baseline. This is bad.
We are testing the change in printing quality which we defined as the accuracy of the inner square made on a mesh grid pattern.

The recorded printing settings are: temperature, speed, and flow rate. We will change one variable and record the changes on the quality, then continue with the next variable.

This project is to see if we can get any stock mass produced 3D printer to optimize printing quailty in real time or improve quality over iterations of printing.

We are adding other parameters and python files for other projects related to this endeavor.
